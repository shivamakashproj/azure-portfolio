## 📌 About the Project

This project is a personal portfolio website created as part of the **Azure Portfolio Launchpad** activity.

The objective of this project is to create a personal portfolio and deploy it publicly using Microsoft Azure cloud services.

The website provides information about my:

- 👤 Profile
- 🎓 Education
- 💻 Technical Skills
- 🚀 Projects
- 📄 Resume
- 📧 Contact Information
